# 自动下料程序（独立运行版）使用说明

> 本说明适用于 GitHub Releases 中发布的“自动下料程序_独立版”压缩包。源码仓库的开发运行方式见项目根目录的 `README.md`。

## 一、运行环境

1. Windows 10/11 64 位电脑。
2. 独立版已随发布包携带运行时，不需要目标电脑安装 Excel、Node.js 或 Codex。
3. Windows 需要已启用 .NET Framework 4.x；Windows 10/11 通常已自带。

## 二、使用方法

1. 将“自动下料程序_独立版”整个文件夹解压到目标电脑的任意位置。
2. 保持文件夹内部结构不变，双击 `自动下料程序.exe`。
3. 点击“选择文件”，选择下料工艺卡 Excel 文件（`.xlsx`）。
4. 按现场要求填写原料定尺、锯缝和取整步长，点击“生成下料方案”。
5. 结果会保存到输入工艺卡所在文件夹，文件名为 `auto_cutting_plan_日期_时间.xlsx`；原工艺卡不会被覆盖。

## 三、重要说明

1. 必须整体携带本文件夹，不能只复制 exe 文件。`engine`、`runtime` 等内部目录不能删除或改名。
2. 程序不需要目标电脑安装 Office，生成的结果可用 Excel 或 WPS 打开。
3. 如果生成失败，请查看程序文件夹内的 `auto_cutting_error.log`；如果是命令行或无窗口模式运行，也可查看 `last_run.log`。
4. 程序当前输出的是“下料方案”“切割明细”和“校核”表；锯床的实际自动下发指令/联机控制仍需根据具体锯床品牌、通信协议和安全联锁另行对接。
5. 导出阶段的后台校验用于辅助发现问题。即使 Excel 文件已经生成，只要日志或“校核”表提示异常，也不能直接用于批量生产，应先复核原料定尺、锯缝、取整步长、数量和长度，并确认校核结果。

## 四、文件夹结构

独立版必须保持类似下面的结构：

```text
自动下料程序_独立版/
├─ 自动下料程序.exe
├─ engine/
├─ runtime/
└─ 其他随包文件
```

源码仓库不提交 exe、Node.js 运行时或 ZIP 发布包；独立版应作为 GitHub Release 附件单独发布。
