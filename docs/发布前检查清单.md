# 公开发布前检查清单

- [ ] 确认代码和算法具备公司/个人公开授权；
- [ ] 删除真实工艺卡、客户名称、项目名称、图号和输出文件；
- [ ] 只保留 `examples/` 中的脱敏示例；
- [ ] 检查代码中没有本机绝对路径、账号、令牌和内部依赖；
- [ ] 执行 `npm install`、`npm test` 和 `npm audit --omit=dev`；
- [ ] 检查 `package-lock.json` 与 `package.json` 已提交；
- [ ] 选择并确认 `LICENSE` 的版权归属；
- [ ] 先在 GitHub 私有仓库验证，再清理 Git 历史后改为公开；
- [ ] 便携版 ZIP 放到 GitHub Releases，不放入源代码目录。
- [ ] 独立版发布包只使用公开依赖版 engine，不得携带任何私有工作区依赖；在干净的 Windows 10/11 电脑上验证双击启动和输出文件名。
- [ ] 独立版说明中的目录结构、日志文件名、输出文件名和“校核”表行为与实际程序一致。
